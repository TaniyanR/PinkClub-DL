# PinkClub-FD

DUGAアフィリエイト商品を紹介する、軽量な商品サイトです。

PinkClub-FLをベースに、DUGA向けとして開発します。

## 開発状況

現在は開発準備中です。

## 使用技術

- PHP
- MariaDB（MySQL）
- JavaScript
- フレームワークなし

## 方針

- 表示速度を重視する
- 既存機能を壊さない
- UI・CSS・レイアウトを必要以上に変更しない
- 最小限の修正で開発する
- `main`へ直接コミットしない
- 作業ブランチとDraft PRを使用する
- 確認・許可を得るまでマージしない

## 注意事項

API ID、アフィリエイトID、パスワードなどの秘密情報は、GitHubへ登録しないでください。
