# PinkClub-DL

DUGAアフィリエイト商品を紹介する、軽量な商品サイトです。

PinkClub-FLをベースに、DUGAの商品検索APIへ対応しています。

## 主な機能

- DUGA API 1.2の商品取得・自動更新
- 商品一覧・商品詳細・検索
- 出演者・カテゴリ・メーカー・レーベル・シリーズ・監督の表示
- ジャケット画像・ダイジェスト画像・サンプル動画の表示
- DUGAアフィリエイトリンク
- 動的SEOメタデータ、OGP画像、構造化データ
- IndexNow通知と掲載終了商品の410 Gone管理
- 管理画面・アクセス解析・相互リンク集計・公開ページキャッシュ

## 使用技術

- PHP
- MariaDB（MySQL）
- JavaScript
- フレームワークなし

## 方針

- 表示速度を重視する
- 既存機能を壊さない
- UI・CSS・レイアウトを必要以上に変更しない
- 最小限の修正で開発する
- `main`へ直接コミットしない
- 作業ブランチとDraft PRを使用する
- 確認・許可を得るまでマージしない

## 注意事項

アプリケーションIDやパスワードなどの秘密情報は、GitHubへ登録しないでください。

DUGAのアプリケーションID・代理店ID・バナーIDは、設置後に管理画面の「API設定」から保存します。

## 本番設置時の必須設定

1. PHP 8系、MariaDB/MySQL、Apacheの `mod_rewrite` を利用できる環境へ配置します。
2. `config.local.php`（Git管理対象外）へDB接続情報を設定し、公開Webルートから直接配信されないことを確認します。
3. 環境変数 `BASE_URL` に、公開サイトのHTTPS URLを末尾スラッシュなしで設定します。
4. `scripts/init_db.php` をCLIで実行するか、管理画面のDB更新を実行し、`sql/migrations/026_partner_link_nofollow.sql` まで適用します。
5. 初期管理者のログインID・パスワードを直ちに固有の値へ変更します。
6. 管理画面の「サイト設定」でサイト名・説明・OGP画像を確認します。
7. 管理画面の「SEO・IndexNow」で送信対象ドメインを確認してからIndexNowを有効にします。
8. Webサーバーが `.htaccess` を読み込み、HTTPS統一、非公開ディレクトリの遮断、静的ファイルのキャッシュ・圧縮が有効であることを確認します。

ログ、キャッシュ、アップロード先はWebサーバーの実行ユーザーだけに必要な書き込み権限を与えてください。`config.local.php`、`.env`、ログ、キャッシュをGitへ追加しないでください。
